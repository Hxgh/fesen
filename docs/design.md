# 飞弦 / Fesen 视觉与交互规范

全端（Windows、macOS、Android 客户端、Web 管理台、`/join` 接入页、原生托盘与快捷磁贴）共享同一套品牌标识、色彩、排版、动效与管理能力组件。公共样式、深浅色、多语言、弹窗菜单、主机聚合卡片与服务端管理视图统一沉淀在 `packages/ui/`（纯零依赖标准 ESM：`base.css`、`icons.js`、`theme.js`、`i18n.js`、`popover.js`、`host-card.js`、`settings.js`、`admin-view.js`），客户端与 Web `/admin/` 直接共用同一份源码，禁止各端私自复制变体。

- **单一登录、自动设备识别、按角色自显管理与清晰来源边界**：全系统只有一套账号与一套登录流程，绝不在客户端内另设第二套“管理员二次登录”。登录无需手填设备类型——客户端原生自动识别当前设备操作系统（`macOS` / `Windows` / `Android` / `Linux`）、主机名与基于系统硬件派生脱敏的唯一设备标识（`machine_id`），重装同机不产生重复设备。任意具备管理员权限的账号（内置 `admin` 或被授予管理员角色的成员账号）正常登录客户端后，自动解锁同身份内存态管理能力，顶栏呈现极简二元导航 **`服务` / `管理`**（桌面支持 `⌘⇧M / Ctrl+Shift+M`），管理台精简为 `成员 / 设备 / 服务` 三栏；普通成员账号零管理入口、顶栏直接显示品牌名。同一账号可多端同时在线，每台设备的本机共享规则本地按账号隔离存储（仅在发布机本机可开关与编辑，跨端不互控开关）；个人对远端服务的备注与 `.fesen` 别名跨端随账号同步，本机规则与本地 `127.0.0.1` 转换按 `machine_id` 独立云端归档备份（重装自动提示恢复、换机可手动导入且导入后共享默认保持关闭）。所有远端已发布服务在「来自组内」分区中明确标注来源设备、自动识别系统标与成员（同账号其他设备标为「本账号 · 设备名」），支持本地 **`127.0.0.1:<自选端口>`** 端口替换（占用时当场提供一键切换推荐空闲端口，并使未含系统路由的 macOS 本地包也能直接访问和预览）。Web `/admin/` 作为极薄兜底壳复用同一套 `admin-view.js`。

## 1. 品牌与 Logo 铁律

- **中文名**：飞弦；**英文名**：Fesen（代码、包名、深链、别名后缀、环境变量使用 `fesen` / `FESEN_*`）。
- **唯一图形**：纯**艮卦 ☶**（上 1 阳爻 + 中 2 阴爻 + 下 2 阴爻，共 5 段直角矩形）。严禁添加圆点、外框、罗盘刻度、光晕、渐变、位移或缩放变形。
- **锁定几何坐标**（`viewBox="0 0 64 64"`，整像素模数，保证 16/20/24/32/64px 锐利不发虚）：
  - 上阳爻：`x=4, y=6, width=56, height=12`
  - 中阴爻：`x=4, y=26, width=24, height=12` 与 `x=36, y=26, width=24, height=12`
  - 下阴爻：`x=4, y=46, width=24, height=12` 与 `x=36, y=46, width=24, height=12`
- **单色八卦三态演进（死门 ☷ → 变爻演卦 → 生门 ☶）**（不换色相，每爻仅由左右两段墨杠向中线相合/退开，绝不在中间填方块插件）：

| 状态 | `data-state` | 卦象与语义 | 呈现方式 |
| --- | --- | --- | --- |
| 未连接 / 离线 | `idle` | **死门 · 坤 ☷ (`000`)**，三阴皆断、弱墨（`0.42`），16px 纯黑白下亦一眼分辨断路 | 静止弱墨 ☷ |
| 连接 / 重连中 | `connecting` | **变爻演卦**（起于死门，从 6 条合法单爻路径中随机择一，搭配轻重缓急非等拍节律；每步仅动一爻，正在变化的变爻凝墨至 `1.0`、余二爻退至 `0.38`，引导视线随气机流转） | 左右两杠自外端向中线伸展汇合 / 退开 |
| 已连通 | `active` | **生门 · 艮 ☶ (`100`)**，连通瞬间以最短单爻步顺滑收束定格，三爻齐亮满墨 `1.0` | 完整满墨 ☶ |

- **跨端载体分工**：
  - **GUI 顶栏 / Web 管理台（`createTrigram()` 共用组件）**：单行 `52px` 顶栏左上角锚点 + 实时 `死门 ☷ → 演卦 → 生门 ☶`（`/join` 页静态展示完整生门 ☶）。
  - **macOS 菜单栏与严格三态（`Menu.swift`）**：`36×36px`（`18×18pt @2x`）实体 `CGImage` 模板图（`isTemplate = true`），由 AppKit 按菜单栏原生前景色精确着色；未连接呈现弱墨死门 ☷、连接/重连中运行同一套单爻演卦（稳态停表 0% 空闲 CPU）、连通后即满墨生门 ☶。开启「留驻菜单栏」时，应用一启动即常驻右上角菜单栏且始终保持最多 1 个 Dock 图标；关窗留驻后 Dock 归零，选择「彻底退出」或点击菜单栏「退出飞弦」则全部进程同步退出。
  - **Windows 托盘（`windows.rs`）**：`32×32` BGRA 原生绘制八卦，跟随系统任务栏深浅色切换墨/白并同步 ☷（未连接）/ ☵（连接中）/ ☶（已连通）。
  - **Android 快捷磁贴（`fesen_tile.xml`）**：纯实心 5 矩形 `VectorDrawable`，亮暗由系统开关接管。
  - **App 启动图标（`mark.svg` 与 Android 自适应图标）**：
    - 桌面端（`apps/desk/native/mark.svg`，`1024×1024` 画布）：遵循 macOS 规范留白，纯墨 `#111315` 圆角底板占 `824×824`（`x=100, y=100, rx=185`），内部居中纯月白 `#f8fafc` 艮卦占 `476×442`（底板宽度的 `57.8%`，`64×64` 网格精确 `8.5×` 缩放）。
    - Android 自适应图标（`apps/desk/native/android-icon/`）：背景纯色 `#111315` 铺满 `108dp`（由系统裁剪原生形状，避免双重圆角与白边），前景矢量艮卦居中占 `42×39dp`（`72dp` 可视区域的 `58.3%`，位于 `66dp` 安全圆内），同步提供 `<monochrome>` 供 Android 13+ 主题图标使用。

## 2. 色彩与表面层级（暖墨宣纸 + 古金主题色）

- **暖调墨纸基底**（浅色宣纸 / 深色松烟墨）：
  - 画布 `--bg`：`#f7f5f0` / `#0c0d0c`
  - 表面 `--surface`：`#ffffff` / `#141514`
  - 轻表面 `--soft`：`#efece5` / `#1c1e1c`
  - 凹槽 `--track`：`#eae6dd` / `#0e0f0e`；抬升 `--elevated`：`#ffffff` / `#242623`
  - 边界 `--line`：`#e3dfd5` / `#252724`；强边界 `--line-strong`：`#cec8ba` / `#373934`
  - 主文 `--ink`：`#1a1815` / `#f2efe9`；次文 `--muted`：`#635f56` / `#969289`；弱文 `--faint`：`#8e897e` / `#67645c`
- **哑光古金主题色（`rgb(199, 169, 107)` / `#c7a96b`）**：
  - 品牌主题与主操作 `--accent` / `--action` / `--good`：**`#c7a96b`**（深色 hover `#d4b97e`、浅色 hover `#b89858`，按钮深墨文字 `--on-action: #14110b` / `#1a160f`，对比度达 AAA 级）；浅底文字强调 `--accent-ink: #8a6e35`（AA 级可读）；轻底 `--tint: rgba(199, 169, 107, 0.13–0.14)`。
  - 统一用于主按钮、在线状态点、激活态拨动开关、已连接 `[ 🔗 ]` 按钮、Tab 激活下划线与焦点环，绝不混入高饱和荧光绿。
  - 警告 / 重叠冲突 `--warn`：浅 `#b7791f` / 深 `#e0a952`
  - 危险 / 不可用 `--bad`（克制朱砂红）：浅 `#c03939` / 深 `#e06c6c`
- **深浅色层级方向一致**：分段控件统一使用凹槽 `--track` + 抬升滑块 `--elevated`（深色下抬升滑块比凹槽亮，绝不出现选中项比底槽更暗的倒置感）。

## 3. 排版、间距与圆角

- 全端采用五阶统一排版与元素比例标尺（支持在设置中选择 **元素大小：`小 / 标准 / 大`**，默认 `标准`，即时生效并本地持久化）：
  - **字体阶梯（`标准`）**：微标计数/协议 `--fs-xs: 11.5px`、次级描述/来源/测速 `--fs-sm: 12.5px`、按钮/输入/端口/菜单/子标题 `--fs-md: 13.5px`、主端点/顶栏导航/弹窗标题 `--fs-base: 14.5px`、品牌标题 `--fs-lg: 16px`；切换 `小 / 大` 时同步按比例调整五阶字号、`--ctl-sm/md/input`、图标尺寸、`osBadge` 微标（`20×18` / `22×20` / `25×23px`）、双层开关（`32×18` / `36×20` / `40×22px`）及各行高度，并通过 `--sub-indent` 动态保持子行左对齐像素锁定。
- 所有 IPv4、端口、CIDR、域名、KPI 数值、计数与版本号统一 `var(--mono)` + `font-variant-numeric: tabular-nums`。
- 间距统一 `4px` 模数；圆角三档：`--radius-sm: 6px`（按钮/徽章）、`--radius: 10px`（卡片/服务行）、`--radius-lg: 14px`（弹窗/登录卡）。
- 桌面默认窗口、记忆尺寸与全端统一顶栏：桌面端默认采用与移动端一致的竖屏伴侣比例 `430×740`（最小 `360×540`、居中启动，自动记住用户调整后的窗口尺寸并在设置中支持一键恢复默认），保证窄窗时 macOS / Windows / Android 视觉与交互完全一致；拉宽窗口至极宽屏时，主容器随屏幕分段平滑扩展（`960px → 1180px (≥1280) → 1480px (≥1600) → 1680px (≥1920) → 2080px (≥2200)`），不采用“本机左 / 组内右”的硬性左右劈半——「本机」与组内设备融入同一统一目录、各自吃满全宽严格齐平，常规模式下主机内部多端口随容器自适应 2–6 列铺开，紧凑模式下无外框平铺网格自动扩展 1–5 列（少条目不留空列，尾部缺格保持完整底分隔线），macOS 顶栏交通灯分割线随窗口宽度平滑衔接。全端统一采用极简单行 `52px` 顶栏（macOS 启用原生 Overlay 隐藏标题栏与系统分割线，红绿灯垂直居中对齐 `26px`，其右侧以 `1px × 16px` 竖向分割线隔开系统区与应用区并顺接 `[ ☷/☶ 飞弦 ]` 或导航；Windows 保留原生窗口标题栏并在顶栏省略重复品牌字样；Android 与 Web 保留左对齐 `[ ☷/☶ 飞弦 ]`）。主题与语言均默认跟随系统（`跟随系统`），手动切换即时生效并持久化缓存；切标签时才播放轻微入场动效，列表内状态更新静止不抖动。未连接服务器时点击服务开关弹窗二次确认，确认后一键自动连接并开启共享。
- 控件尺寸与元素语法铁律（避免图标与文字随意混用、避免冗余辅助说明）：
  - **统一图标按钮家族（`.icon-btn`）+ 同类同样式**：全端所有图标按钮统一收口至 `packages/ui/icons.js` (`createIconButton`) 与 `base.css` (`.icon-btn`)，按场景区分实体表面（`.solid`：`--soft` + `1px solid --line`，用于顶栏主控 `lg:30px` 与网页预览窗 `md:28px`）与轻量表面（`.ghost`：平时透明、悬停 `--soft`、激活/展开 `--tint` + `--accent-ink`，用于行轨与管理台工具 `md:28px` 及列表工具栏与行内移除 `sm:24px`，均支持 `.dropdown` 携带小下拉箭头）；全端图标按钮均配备 `title` 与 `aria-label`。
  - **紧凑网页预览窗（单栏顶条 + 100% 内容 + 放大切换）**：预览窗默认紧凑（桌面 `560×440`），仅保留顶部单行 `42px` 栏（左：状态点 + URL + 极简状态词；右：同款 `.icon-btn` `[ ↻ ]` `[ ⤢ ]` `[ × ]` 带 hover 提示），无底部占高栏，桌面支持一键放大/还原并实时同步原生 WebView 区域。
  - **设置弹窗等宽对齐与即时生效**：所有设置项统一走左侧标签 + 右侧等宽分段控件（`216px`），即时生效无冗余确认按钮；弹窗打开聚焦容器本身，不在关闭按钮 `×` 上触发突兀焦点框。
  - **行级下拉菜单（icon + 文字）**：点击 `⋯` 原地展开 `.popover-menu`（`14px` 图标 + 文字，支持单选当前项 `✓` 高亮），整合「网页预览 / 浏览器打开 / 复制命令 / 复制地址 / 编辑与设置」，避免弹窗打断与行内按钮堆砌。
  - **严格右轨对齐与真双层开关**：主机头与端口行共享同一 `28px` 最右图标轨（`+` / `↻` / `⋯` 垂直对齐）与紧邻其左的 `34×20px` 真双层拨动开关列（凹槽轨道 + 实体圆滑块平滑位移，主机总开关与子端口开关像素级垂直对齐）。
  - **让布局本身解释**：不放冗余列表表头、不放与协议标重复的左侧大灰图标盒、不在拨动开关旁重复写“共享中/未共享”文字、不在状态胶囊内堆砌刷新图标、不在弹窗内堆砌说明性段落、不在已显示 IP + OS 微标的主机下重复打印 `OS · IP` 副标题。
  - **单行不折行与全端弹窗统一**：服务行（桌面 `44px`）与主机端口行（桌面 `34px`，触控屏 `@media (pointer: coarse)` 保持 `≥ 40px`）统一 `28px` 控件高度，在桌面端和 360px 移动端均保持单行对齐，健康态状态仅小圆点 + 精炼耗时/状态码；所有弹窗共享同一头部结构（标题 + 右上角 `28×28` 关闭 `×`），即时生效弹窗不重复放底部「完成/关闭」按钮。
  - **四级合并规整与统一目录（「本机」融入列表）**：服务列表将「本机」作为当前账号的第一台设备直接融入统一目录，不再在标题旁重复拼贴「本机 / 本账号」文字标签，而直接通过本机前置系统标识的主题色微标（`osBadge` 主题态）予以区分（悬停 `title` 与 `aria-label` 展示 `本机 · 本账号 · 系统` 等完整详情），按 `同账号多设备聚合（仅 ≥2 台设备时显性包框）→ 设备/单主机聚合（单设备单 IP 去重合并为一张卡片，单服务合并为单行，多 IP 同设备收拢于一张设备卡片内并以 `1px` 分割线逐台分隔）→ 多端口主机` 组织；多设备账号组、设备/主机卡与子主机均支持点击左侧标题区折叠（按账号持久化状态），右侧开关、`+` 与 `[ ↻ ]`/`[ ⋯ ]` 独立直点不误触折叠。
  - **极简统一列表顶部工具栏（常驻搜索框 + 等高纯图标视图切换）**：因列表内已天然将「本账号」与主题色标「本机」置顶并支持一键折叠展开，顶部工具栏摒弃冗余的范围分栏，仅保留严格等高 `--ctl-sm`（`28/30/34px`，`7px` 圆角、`--track` 基底）的一左一右两枚对称控件——左侧为全端常驻搜索框（`max-width: 340px`，支持名称、成员、设备、IP、端口及「本机 / 本账号」关键词直筛，支持 `⌘F / Ctrl+F` 聚焦与 `Esc` 清空），右侧为纯图标三态分段切换 `[ 常规(cards) | 紧凑(list) | 收起(collapse) ]`（1 击直达、悬停展示名称）。
  - **封装前置操作系统标识（`osBadge`）**：所有设备与主机的操作系统（`Windows` / `macOS` / `Linux` / `Android`）统一封装为随 `--os-w / --os-h` 缩放的轻底圆角图标微标（`标准` 为 `22×20px` + `13.5px` 端正单色品牌图标），固定置于标题/地址最前方（未识别目标以默认 `server` / `device` 图标占位保持全列垂直对齐）；本机节点直接采用古金主题色底框标识，组内远端节点采用中性宣纸/松烟墨微标，悬停 `title` 与 `aria-label` 展示完整归属与系统名称。
  - **主机弹窗宽屏自适应（`.dialog-wide`）**：「新增共享 / 管理主机」弹窗在窄屏与默认窗维持 `420px` 单列；`≥ 720px` 自动展宽至 `720px`、`≥ 1040px` 展宽至 `840px`，IP 与名称并排省高，且端口达到 6 个以上时端口清单自动切换双列排布，消除大主机管理时的窄槽局促感。
- 主机聚合与动态能力微标：新增共享统一为单一表单（无割裂模式页签），支持单 IP 与网段/端口段；单 IP 可点击 `[ ↻ ]`（发现服务）秒级探测精选高频服务池（30+ 常用 Web/远程/中间件端口，若目标为本机 IP 则直读系统监听表含进程名提示），并可按需点击「深度探测 (1–10000)」发掘冷门开放端口；探测过程中点击「取消扫描」或关闭弹窗可立即中止扫描并释放底层连接；在同一个端口容器内勾选或回车追加端口。系统微标（`Windows`/`Linux`）与特征端口（SSH/RDP）强联动——勾选/保留对应特征端口时自动展示，取消勾选或删除全部特征端口后立即自动撤销，绝不残留假标识。单 IP 多端口自动聚合为主机卡片，系统标与协议标统一使用中性墨纸底色与等宽微标签。
- **主机与服务全链路编辑及删除**：本机单服务与单端口均支持从行菜单 `⋯` 直接进入「编辑共享」（含正在共享中热改并可选自动续播）或一键「删除」；多端口主机头右侧提供 `⋯` 菜单直达「管理主机」（同窗内支持追加/探测新端口、修改协议、改主机名而不覆盖单端口自定义子名称、取消勾选标记删除单端口，或左下角一键「删除主机」原子停用并移除全部端口）。远端网段服务支持在「访问设置」中逐条查看与删除已配的 `127.0.0.1` 本地端口转换。
- 平台诚实原则：只展示当前平台真实生效的设置项（如关闭窗口留驻菜单栏仅在 macOS 显示，不在 Android/Windows 放无效控件）。
- **本地 `127.0.0.1` 端口转换与占用闭环**：使用方可在任意远端服务的「访问设置」中绑定本机回环 `127.0.0.1:<自选端口>`（仅监听 `127.0.0.1`，绝不监听 `0.0.0.0`），彻底避开本地端口占用、跨端同名同段碰撞或兼容性限制。若保存或重连时检测到端口被本机其他进程占用，核心自动探测一个真正可用的空闲端口并在卡片、行菜单及弹窗内提供一键「改用」恢复；配置生效后，列表展示、复制命令/地址、浏览器打开与网页预览统一自动切换为转换后的 `127.0.0.1` 入口。
- **启动自动连接与同网安全恢复**：支持在设置中配置「启动时连接」（默认 `自动连接` / 可切 `手动连接`）与「恢复上次共享」（默认 `同网自动` / 可切 `不开启`）及「云端备份规则」（默认 `开启`）。已登录账号重新打开客户端时默认自动接入组；若启用同网自动恢复，仅在当前物理网络指纹与退出前一致时自动恢复之前开启中的共享服务，一旦检测到切换至陌生网络则安全拦截自动开启并给出提示，绝不跨网盲目暴露内网服务。

## 4. 动效与无障碍

- 统一缓动 `cubic-bezier(0.22, 1, 0.36, 1)`：微交互 `140ms`，卡片/弹窗/面板入场 `180–200ms`，禁止夸张弹跳与多余装饰动画。
- 所有弹窗支持 `Esc` 与背景点击关闭（提交中除外），交互元素保留 `:focus-visible` 焦点环与语义 `aria-*` 属性。
- 严格遵循 `@media (prefers-reduced-motion: reduce)`：关闭位移动效与循环呼吸，握手态降为静止中态。

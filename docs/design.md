# 飞弦 / Fesen 视觉与交互规范

全端（Windows、macOS、Android 客户端、Web 管理台、`/join` 接入页、原生托盘与快捷磁贴）共享同一套品牌标识、色彩、排版与动效规则。公共样式与矢量组件集中在 `packages/ui/base.css` 和 `packages/ui/icons.js`，禁止各端私自复制变体。

## 1. 品牌与 Logo 铁律

- **中文名**：飞弦；**英文名**：Fesen（代码、包名、深链、别名后缀、环境变量使用 `fesen` / `FESEN_*`）。
- **唯一图形**：纯**艮卦 ☶**（上 1 阳爻 + 中 2 阴爻 + 下 2 阴爻，共 5 段直角矩形）。严禁添加圆点、外框、罗盘刻度、光晕、渐变、位移或缩放变形。
- **锁定几何坐标**（`viewBox="0 0 64 64"`，整像素模数，保证 16/20/24/32/64px 锐利不发虚）：
  - 上阳爻：`x=4, y=6, width=56, height=12`
  - 中阴爻：`x=4, y=26, width=24, height=12` 与 `x=36, y=26, width=24, height=12`
  - 下阴爻：`x=4, y=46, width=24, height=12` 与 `x=36, y=46, width=24, height=12`
- **单色八卦三态演进（死门 ☷ → 单爻演卦 → 生门 ☶）**（不换色相，每爻仅以中央 8px 断桥合拢/分开切换阴阳）：

| 状态 | `data-state` | 卦象与语义 | 呈现方式 |
| --- | --- | --- | --- |
| 未连接 / 离线 | `idle` | **死门 · 坤 ☷ (`000`)**，三阴皆断、弱墨（`0.44`），16px 纯黑白下亦一眼分辨断路 | 静止弱墨 ☷ |
| 连接 / 重连中 | `connecting` | **单爻演卦**（起于死门，从 4 条合法单爻路径中随机择一推演，每步仅变一爻、绝不乱闪不走回头路；慢网则非回头单爻邻步游走且避开提前落定 ☶） | 中央断桥 `scaleX(0 ↔ 1)` 丝滑合拢/分开 |
| 已连通 | `active` | **生门 · 艮 ☶ (`100`)**，连通瞬间以最短单爻步顺滑收束定格，满墨 `1.0` | 完整满墨 ☶ |

- **跨端载体分工**：
  - **GUI 顶栏 / Web 管理台（`createTrigram()` 共用组件）**：单行 `52px` 顶栏左上角锚点 + 实时 `死门 ☷ → 演卦 → 生门 ☶`（`/join` 页静态展示完整生门 ☶）。
  - **macOS 菜单栏（`Menu.swift`）**：`36×36px`（`18×18pt @2x`）实体 `CGImage` 模板图（`isTemplate = true`），由 AppKit 按菜单栏原生前景色精确着色；未连接呈现弱墨死门 ☷、连接/重连中运行同一套单爻演卦（稳态停表 0% 空闲 CPU）、连通后即满墨生门 ☶。
  - **Windows 托盘（`windows.rs`）**：`32×32` BGRA 原生绘制八卦，跟随系统任务栏深浅色切换墨/白并同步 ☷（未连接）/ ☵（连接中）/ ☶（已连通）。
  - **Android 快捷磁贴（`fesen_tile.xml`）**：纯实心 5 矩形 `VectorDrawable`，亮暗由系统开关接管。
  - **App 启动图标（`mark.svg` 与 Android 自适应图标）**：
    - 桌面端（`apps/desk/native/mark.svg`，`1024×1024` 画布）：遵循 macOS 规范留白，纯墨 `#111315` 圆角底板占 `824×824`（`x=100, y=100, rx=185`），内部居中纯月白 `#f8fafc` 艮卦占 `476×442`（底板宽度的 `57.8%`，`64×64` 网格精确 `8.5×` 缩放）。
    - Android 自适应图标（`apps/desk/native/android-icon/`）：背景纯色 `#111315` 铺满 `108dp`（由系统裁剪原生形状，避免双重圆角与白边），前景矢量艮卦居中占 `42×39dp`（`72dp` 可视区域的 `58.3%`，位于 `66dp` 安全圆内），同步提供 `<monochrome>` 供 Android 13+ 主题图标使用。

## 2. 色彩与表面层级

- **中性墨纸基底**（浅色 / 深色）：
  - 画布 `--bg`：`#f7f8f7` / `#0c0e0d`
  - 表面 `--surface`：`#ffffff` / `#141716`
  - 轻表面 `--soft`：`#eff2f0` / `#1c211f`
  - 边界 `--line`：`#e2e6e4` / `#262d2a`
  - 主文 `--ink`：`#111513` / `#f1f4f2`；次文 `--muted`：`#58635d` / `#93a099`；弱文 `--faint`：`#84908a` / `#64716a`
- **克制语义色**（绝不侵入 Logo，也不大面积铺染按钮或卡片）：
  - 主操作按钮 `--action` 走墨纸反色（浅底墨黑 `#141816`、深底月白 `#eef1ef`），保证与单色纯艮卦视觉完全一致；
  - 在线 / 开关激活 `--good`：浅 `#059669` / 深 `#34d399`（仅用于 `6px` 状态点与拨动开关，不铺满整张卡片或主按钮）
  - 警告 / 重叠冲突 `--warn`：浅 `#c27803` / 深 `#f5b942`
  - 危险 / 不可用 `--bad`：浅 `#dc2626` / 深 `#f87171`
- **深浅色层级方向一致**：分段控件统一使用凹槽 `--track` + 抬升滑块 `--elevated`（深色下抬升滑块比凹槽亮，绝不出现选中项比底槽更暗的倒置感）。

## 3. 排版、间距与圆角

- 正文走系统无衬线字体 `15px / 1.5`；所有 IPv4、端口、CIDR、域名、KPI 数值、计数与版本号统一 `var(--mono)` + `font-variant-numeric: tabular-nums`。
- 间距统一 `4px` 模数；圆角三档：`--radius-sm: 6px`（按钮/徽章）、`--radius: 10px`（卡片/服务行）、`--radius-lg: 14px`（弹窗/登录卡）。
- 桌面默认窗口与单行顶栏：桌面端默认采用与移动端一致的竖屏伴侣比例 `430×740`（最小 `360×540`、居中启动，可自由拉宽至 `--wrap: 820px`），保证 macOS / Windows / Android 视觉与交互完全一致；客户端与 Web 管理台均采用极简单行 `52px` 顶栏（左：`☷/☶` + 导航标签；右：全套同款图标按钮）。
- 控件尺寸与元素语法铁律（避免图标与文字随意混用、避免冗余辅助说明）：
  - **同类同样式 + 全系统图标优先（均带 hover 提示）**：同组并排控件必须使用完全一致的表面底色、边框、前景色与高度（禁止一个实心按钮紧挨一个无背景透明按钮）。顶栏与工具栏统一采用 `.tool-btn`（`30px` 桌面 / `32px` 移动、`--soft` 底 + `1px solid --line` 框，所有图标按钮配备 `title` 与 `aria-label`）：顶栏右侧恒定双等大图标 `[ ⛓̸ / ↻ / 🔗 ]`（一键直连/直断，零多余连接弹窗、不以「仅共享」替代已连接状态）+ `[ ⚙ ]`（设置含账号与退出登录）；标签栏 `[ + ]`；主机检测 `[ ↻ ]`；表单底部取消与主操作同为有框实体按钮。
  - **紧凑网页预览窗（单栏顶条 + 100% 内容 + 放大切换）**：预览窗默认紧凑（桌面 `560×440`），仅保留顶部单行 `42px` 栏（左：状态点 + URL + 极简状态词；右：同款 `[ ↻ ]` `[ ⤢ ]` `[ × ]` 图标按钮带 hover 提示），无底部占高栏，桌面支持一键放大/还原并实时同步原生 WebView 区域。
  - **设置弹窗等宽对齐与即时生效**：所有设置项统一走左侧标签 + 右侧等宽分段控件（`216px`），即时生效无冗余确认按钮；弹窗打开聚焦容器本身，不在关闭按钮 `×` 上触发突兀焦点框。
  - **行级下拉菜单（icon + 文字）**：点击 `⋯` 原地展开 `.popover-menu`（`14px` 图标 + 文字），整合「网页预览 / 浏览器打开 / 复制命令 / 复制地址 / 编辑与设置」，避免弹窗打断与行内按钮堆砌。
  - **严格右轨对齐与真双层开关**：主机头与端口行共享同一 `28px` 最右图标轨（`+` / `↻` / `⋯` 垂直对齐）与紧邻其左的 `34×20px` 真双层拨动开关列（凹槽轨道 + 实体圆滑块平滑位移，主机总开关与子端口开关像素级垂直对齐）。
  - **让布局本身解释**：不放冗余列表表头、不放与协议标重复的左侧大灰图标盒、不在拨动开关旁重复写“共享中/未共享”文字、不在状态胶囊内堆砌刷新图标、不在弹窗内堆砌说明性段落、不在已显示 IP + OS 微标的主机下重复打印 `OS · IP` 副标题。
  - **单行不折行与全端弹窗统一**：服务行与主机端口行统一 `28px` 控件高度，在桌面端和 360px 移动端均保持单行对齐，健康态状态仅小圆点 + 精炼耗时/状态码；所有弹窗共享同一头部结构（标题 + 右上角 `28×28` 关闭 `×`），即时生效弹窗不重复放底部「完成/关闭」按钮。
- 主机聚合与动态能力微标：新增共享统一为单一表单（无割裂模式页签），支持单 IP 与网段/端口段；单 IP 可点击 `[ ↻ ]` 探测常用服务，在同一个端口容器内勾选或回车追加端口。系统微标（`Windows`/`Linux`）与特征端口（SSH/RDP）强联动——勾选/保留对应特征端口时自动展示，取消勾选或删除全部特征端口后立即自动撤销，绝不残留假标识。单 IP 多端口自动聚合为主机卡片，系统标与协议标统一使用中性墨纸底色与等宽微标签。
- 平台诚实原则：只展示当前平台真实生效的设置项（如关闭窗口留驻菜单栏仅在 macOS 显示，不在 Android/Windows 放无效控件）。

## 4. 动效与无障碍

- 统一缓动 `cubic-bezier(0.22, 1, 0.36, 1)`：微交互 `140ms`，卡片/弹窗/面板入场 `180–200ms`，禁止夸张弹跳与多余装饰动画。
- 所有弹窗支持 `Esc` 与背景点击关闭（提交中除外），交互元素保留 `:focus-visible` 焦点环与语义 `aria-*` 属性。
- 严格遵循 `@media (prefers-reduced-motion: reduce)`：关闭位移动效与循环呼吸，握手态降为静止中态。

# 飞弦 / Fesen 视觉与交互规范

## 0. 主导原则

- **唯一真源（`packages/ui/`）**：客户端、Web `/admin/` 与 `/join` 共用同一套 CSS 令牌（`styles/{tokens,layout,controls,surfaces,responsive}.css`）与零依赖 ESM 组件（`icons.js`、`theme.js`、`i18n.js`、`popover.js`、`host-card.js`、`settings.js`、`admin-view.js`）。禁止各端私自复制变体或在 `tokens.css` 之外硬编码色值、透明度或阴影。
- **平台诚实**：只呈现当前平台真实生效的控件（如「留驻菜单栏」仅在 macOS 显示，Web `/admin/` 无本地节点不展示连接与切换控件）。
- **克制留白、让布局自解释**：不放冗余表头、说明段落、重复状态词或无意义装饰；相同语境的控件外观与高度严格一致。

## 1. 品牌与八卦标识铁律

- **命名**：中文「飞弦」，英文「Fesen」；代码、深链、`.fesen` 别名与环境变量统一 `fesen` / `FESEN_*`。
- **唯一图形**：纯**艮卦 ☶**（上 1 阳爻 + 中 2 阴爻 + 下 2 阴爻，5 段直角矩形）。严禁添加外框、圆点、光晕、渐变、色彩变化或缩放位移。
- **锁定坐标**（`viewBox="0 0 64 64"`）：
  - 上阳爻：`x=4 y=6 w=56 h=12`
  - 中阴爻：`x=4 y=26 w=24 h=12`、`x=36 y=26 w=24 h=12`
  - 下阴爻：`x=4 y=46 w=24 h=12`、`x=36 y=46 w=24 h=12`
- **单色三态演进**（`createTrigram()`，左右两段墨杠自外向中伸展汇合/退开）：

| 状态 | `data-state` | 卦象与墨度 | 呈现 |
| --- | --- | --- | --- |
| 离线 / 未连接 | `idle` | 死门 · 坤 ☷（`000`），弱墨 `--yao-idle`（`0.42`） | 静止三断爻 |
| 连接 / 重连中 | `connecting` | 变爻演卦（6 条单爻路径、非等拍节律；变爻 `1.0`、余爻 `--yao-dim` `0.38`） | 逐爻墨杠伸展 |
| 已连通 | `active` | 生门 · 艮 ☶（`100`），最短单爻步收束，满墨 `1.0` | 完整满墨 ☶ |

- **全端载体**：
  - **顶栏 / Web `/admin/`**：`20×20` 动态 `createTrigram()`；`/join` 静态展示 ☶。
  - **macOS 菜单栏（`Menu.swift`）**：`36×36px`（`18pt @2x`）`isTemplate = true` 模板图，遵循同一三态（稳态 0% 轮询）。
  - **Windows 托盘（`windows.rs`）**：`32×32` BGRA 原生绘制，随任务栏深浅色切换墨/白并映射 ☷ / ☵ / ☶。
  - **Android 磁贴（`fesen_tile.xml`）**：5 矩形纯色 `VectorDrawable`，亮暗交由系统。
  - **App 启动图标**：`mark.svg`（`1024×1024`）底板 `#111315`（`824×824, rx=185`）居中月白 `#f8fafc` 艮卦（`476×442`）；Android 自适应图标 `#111315` 铺满 `108dp`，前景艮卦占 `42×39dp` 并附 `<monochrome>`。

## 2. 色彩标准与令牌体系

采用 **三层架构**（定义于 `packages/ui/styles/tokens.css`）：`原语色板 (--fesen-*)` → `语义角色` → `组件消费`。主调为**暖墨宣纸（浅）/ 松烟墨（深）**中性基底，搭配唯一品牌主导色**哑光古金（`#c7a96b`）**，严禁混入高饱和荧光绿或其他无序彩点。

| 层级 | 语义令牌 | 浅色（宣纸） | 深色（松烟墨） | 主导用途 |
| --- | --- | --- | --- | --- |
| 表面 | `--bg` / `--surface` / `--soft` | `#f7f5f0` / `#ffffff` / `#efece5` | `#0c0d0c` / `#141514` / `#1c1e1c` | 画布、主卡片、轻按钮底 |
| 凹凸 | `--track` / `--elevated` | `#eae6dd` / `#ffffff` | `#0e0f0e` / `#242623` | 分段凹槽与抬升滑块（深浅同向抬升） |
| 边线 | `--line` / `--line-strong` | `#e3dfd5` / `#cec8ba` | `#252724` / `#373934` | 常规描边、悬浮与分割线 |
| 文字 | `--ink` / `--muted` / `--faint` | `#1a1815` / `#635f56` / `#8e897e` | `#f2efe9` / `#969289` / `#67645c` | 主标题/端点、次级元信息、弱提示 |
| 品牌主导 | `--accent` / `--action` / `--good` | `#c7a96b`（`--fesen-gold`） | `#c7a96b`（`--fesen-gold`） | 主按钮、开关激活、在线点、本机标识、焦点环 |
| 品牌文字/轻底 | `--accent-ink` / `--tint` / `--on-action` | `#8a6e35` / `rgba(199,169,107,.14)` / `#1a160f` | `#c7a96b` / `rgba(199,169,107,.13)` / `#14110b` | 浅底文字对比（AA）、激活轻底、主按钮字（AAA） |
| 警告 | `--warn` / `--warn-bg` | `#b7791f` / `#fdf5e6` | `#e0a952` / `rgba(224,169,82,.14)` | 地址重叠映射、本地端口占用 |
| 危险 | `--bad` / `--bad-bg` | `#c03939` / `#fdf0f0` | `#e06c6c` / `rgba(224,108,108,.14)` | 停用、撤销、删除与错误提示 |
| 深度与遮罩 | `--shadow-{xs,sm,md,lg,toast}` / `--scrim` | 统一令牌 | 统一令牌 | 滑块、登录卡、菜单、弹窗、Toast、遮罩 |

## 3. 排版、尺度与布局规范

- **三档全局尺度**（`data-scale="sm|md|lg"`，默认 `md`，即时生效并持久化）：

| 档位 | 五阶字号 `xs / sm / md / base / lg` | 控件 `ctl-sm / md / input` | 图标钮 `sm / md / lg` | OS 标 `w×h` | 开关 `w×h` | 行高 `port / srv` |
| --- | --- | --- | --- | --- | --- | --- |
| `sm` | `10.5 / 11.5 / 12.5 / 13.5 / 15` | `28 / 30 / 34` | `24 / 26 / 28` | `20×18` | `32×18` | `34 / 46` |
| `md`（默认） | `11.5 / 12.5 / 13.5 / 14.5 / 16` | `30 / 32 / 38` | `26 / 28 / 32` | `22×20` | `36×20` | `38 / 50` |
| `lg` | `12.5 / 13.5 / 15 / 16 / 17.5` | `34 / 36 / 42` | `30 / 32 / 36` | `25×23` | `40×22` | `44 / 56` |

- **数值与圆角**：IPv4、端口、CIDR、域名、计数与耗时统一 `var(--mono)` + `tabular-nums`；圆角锁定 `--radius-sm: 6px`、`--radius: 10px`、`--radius-lg: 12px`。
- **窗口与响应式容器**：桌面默认竖屏伴侣 `430×740`（最小 `360×540`，记住尺寸并支持重置）；客户端主容器随宽度分段扩展（`960 → 1180 → 1480 → 1680 → 2080px`），Web `/admin/` 固定 `--wrap: 900px`。
- **统一单行顶栏（`52px`）**：
  - 左侧始终为纯 `[ ☷/☶ 飞弦 ]`（macOS Overlay 交通灯右侧加 `1×16px` 竖线隔开；Windows 保留系统标题栏并隐藏顶栏品牌字样）。
  - 右侧纯增强工具区：普通用户 `[ + ] [ 🔗 ] [ ⚙ ]`；管理员额外在最左端以竖线分隔追加切换钮 `[ console ] | [ + ] [ 🔗 ] [ ⚙ ]`（支持 `⌘⇧M / Ctrl+Shift+M`），进入管理工作区后变为 `[ home ] | [ 🔗 ] [ ⚙ ]`；Web `/admin/` 仅保留 `[ ⚙ ]`。
  - 管理工作区在客户端与 Web `/admin/` 共用 `.panel-bar`（底线页签 `成员 / 设备 / 服务` + `[ + | ↻ | 分享接入链接 ]`），本机设备以古金 `osBadge` + 「本机」标签置顶且禁止自撤销。
- **统一服务目录与核心组件语法**：
  - 本机作为当前账号首台设备直接融入目录，由前置 `osBadge` 标识系统与归属（古金底框 = 本机，中性底框 = 远端；无系统信息时用 `server`/`device` 占位对齐）。
  - 顶部单行工具栏等高 `--ctl-sm`：左常驻搜索（`⌘F / Esc`），右三态纯图标视图切换 `[ 常规 | 紧凑 | 收起 ]`。
  - 所有图标钮统一走 `createIconButton()`（`.icon-btn.solid` 用于顶栏/预览栏，`.icon-btn.ghost` 用于行轨/管理栏），并配 `title` 与 `aria-label`。
  - 右轨像素对齐：主机头与子端口共享最右图标轨与紧邻双层拨动开关；行操作统一收口至 `⋯` 原地 `.popover-menu`。
  - 弹窗规范：统一 `dialog-header`（标题 + 右上角 `×`），设置弹窗左标签 + 右等宽分段（`--settings-ctl: 224px`）即时生效；新增/管理主机宽屏自适应（`.dialog-wide`）；网页预览窗单行 `42px` 顶栏 + 100% 内容区 + 桌面放大切换。

## 4. 动效与无障碍

- 缓动 `--ease: cubic-bezier(0.22, 1, 0.36, 1)`，微交互 `140ms`，入场 `180–200ms`；仅切换标签/弹窗时入场，列表状态刷新不抖动。
- 所有弹窗支持 `Esc` 与遮罩点击关闭（提交中除外），打开聚焦容器本身；保留 `:focus-visible` 古金焦点环与 `aria-*` 语义；触控屏（`pointer: coarse`）保证行高与按钮最小触控热区；遵循 `prefers-reduced-motion: reduce`。

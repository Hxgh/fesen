# 产品边界与验收

同一服务器即同一个组。客户端同时支持发布与访问，只交付 IPv4/TCP（不转发 UDP/ICMP），不实现业务中继、公开注册、网段扫描或代理配置。

## 设计边界

- **控制面与数据同步**：HTTPS/WSS 控制面；SQLite 持久化账号、设备（自动识别系统与硬件派生 `machine_id`）、会话、账号级偏好（`member_prefs` 跨端同步）与设备配置快照（`device_profiles` 按 `machine_id` 独立归档）。接入链接仅含服务器地址（`fesen://join?server=...`）。仅禁止同一设备发布自冲突规则，允许不同设备发布重叠内网目标。
- **直连与鉴权**：双向 TLS 1.3 QUIC 直连；macOS / Android 自动并试 IPv4 与公网 IPv6；可选内置 UDP 或外部 STUN 辅助公网 IPv4 探测（与 QUIC 复用同一 UDP socket）；无可用路径直接报无法直连。每次建流在发布端复验设备身份、最长 60 秒的授权租约及 `地址 × 端口` 规则；停用、关共享或切换物理网络立即取消对应流。
- **单机发现与聚合**：仅对用户输入的单个非保留 IPv4 发起定向只读探测（常规探测 ~33 个常见端口，本机 IP 直读系统监听表；按需深度探测 `1–10000` 并跳过 OS RPC 噪音，零认证请求、零网段扫描），自动识别协议与系统并聚合成主机卡片。
- **分流与 `127.0.0.1` 转换**：仅安装共享目标 IPv4 路由，非默认本地路由优先；本地重叠或跨端碰撞时自动分配虚拟 IPv4（`198.18.x.y`），不改动原路由。支持为任意远端目标配置本机 `127.0.0.1:<端口>` 转发（占用时推荐空闲端口一键切换），无系统路由亦可直连与预览；`.fesen` 别名走系统 DNS。
- **三端运行形态**：Windows 10/11 (x64) 用 Wintun + 独立核心 + 原生托盘；macOS 14+ (Apple Silicon) 用 Network Extension + 原生菜单栏（本地未签名包可发布并借 `127.0.0.1` 转发访问）；Android 13+ (ARM64) 用独立 `VpnService` + 快捷磁贴且不申请通知权限。Tauri 仅走本机 IPC，不接触数据流。

## 完成判据

| 范围 | 必须验证的行为 |
| --- | --- |
| 服务端 | 部署与重启；无注册入口；建号、停用、重置、赋权与设备撤销；默认仅 HTTPS/WSS；无业务中继 |
| 目录 | 默认无共享；范围端点与同 IP 不同端口共存；跨设备重叠由本地避让/转换；同设备冲突拒绝；关共享即下架 |
| 安全 | QUIC 互认；伪造设备与越界目标被拒；撤权中断既有流；控制面失联最迟 60 秒租约过期；换网暂停 |
| 原应用 | 原应用直访原地址；同 IP 不同端口命中对应设备；重叠时原地址走本地，虚拟地址与 `.fesen` 访问远端 |
| 失败 | 明确区分设备离线、无法直连、地址/端口冲突、未授权与目标超时 |
| 连通测试 | 经直连与 ACL 检测目标并返回耗时：TCP/SMB 验建连、SSH 读 Banner、RDP 走 X.224、HTTPS 验 ServerHello、HTTP 验 `GET /` 2xx 且不跟随跳转 |
| 单机发现 | 拒绝保留地址与超量端口，快速识别开放服务与系统；单 IP 多端口聚合为主机卡片，支持整机开关与按协议复制命令 |
| 网页预览 | HTTP 服务可应用内预览、重试与关闭；准确反馈网页或失败原因，本机预览单独标注，重叠走虚拟/127 地址 |
| 生命周期 | 桌面关窗 GUI 退出而流不中断、托盘无 WebView、空闲核心自动退出清路由；Android 按需启停 VPN 且无通知权限申请 |
| 界面 | 遵循 [视觉与交互规范](design.md)：`packages/ui` 单一真源、八卦三态、深浅色与中英切换、客户端与 Web 管理台一致 |
| 日志 | 仅存本机（上限 10 MiB / 7 天），不记录密码、令牌或业务数据 |

共有逻辑通过单元与集成测试；虚拟网卡、系统 DNS、签名授权、托盘/磁贴与真实 NAT 直连须在目标平台实机验收，交叉编译不计作实机通过。

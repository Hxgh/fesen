# 交付目标与验收

同一服务器上的账号自动属于同一个组。客户端可同时访问和发布；目录中的在线共享由发布设备实际执行。只交付 IPv4/TCP（不转发 UDP 或 ICMP ping），不实现业务中继、注册、网段扫描或代理配置。

## 设计边界

- 控制面使用 HTTPS/WSS；SQLite 持久化账号、设备与会话。发布绑定在线设备。管理员可建号、重置、停用或撤销设备。接入链接只包含服务器地址（`fesen://join?server=...`）。
- 数据面使用双向认证的 QUIC（TLS 1.3）。默认只交换设备地址；macOS 和 Android 同时尝试可用的 IPv4 和公网 IPv6 直连。管理员可选内置 UDP 或指定 STUN 做 IPv4 公网地址探测，探测与 QUIC 使用同一个 UDP socket。没有可用路径时直接报错，不转发业务流量。
- 发布以「地址清单 × 端口清单」匹配；仅两项范围都交叠才冲突。每次连接都在发布端检查设备身份、授权租约和本地范围。停用、关共享和物理网络变化取消对应连接；失联授权租约最长 60 秒。
- 单机能力识别与聚合：发布端「按主机添加」仅对用户输入的**单个合法非保留 IPv4** 由核心底层网卡发起定向只读探测（固定 5 个标准端口 `22/3389/445/80/443` + 最多 5 个附加端口，单端口连接超时 1 秒，零认证请求、零网段扫描、零后台轮询）；同一发布者的同一单 IP 多端口在界面自动聚合为主机卡片并展示识别出的系统（`Windows`/`Linux`）与协议能力（`SSH`/`RDP`/`SMB`/`HTTP`/`HTTPS`）。
- 客户端只安装共享目标的 IPv4 路由。非默认本地路由优先；重叠地址换用独立虚拟 IPv4，不修改原路由。备注和 `.fesen` 访问别名仅保存在当前客户端，后者通过系统 DNS 路径解析。没有发布的端口不通过隧道；同一个被捕获原 IP 的其他 TCP 端口走原网络。
- Windows 10/11 (x64)：Wintun + 独立 Rust 核心 + 原生托盘。macOS 14+ (Apple Silicon)：Network Extension 进程中的 Rust 核心 + 原生菜单栏；本地测试签名包仅发布，不安装路由。Android 13+ (ARM64)：独立 `VpnService` 进程，应用或快捷磁贴可断开，不申请通知权限。Tauri 只通过本机 IPC 操作核心，不接触数据流。

## 完成判据

| 范围 | 必须验证的行为 |
| --- | --- |
| 服务端 | 部署与重启；无注册入口；新增账号、不可用密码、停用和设备撤销；默认仅 HTTPS/WSS；无业务中继 |
| 目录 | 默认无共享；仅访问的设备可用；范围端点、同 IP 不同端口、交集拒绝、关共享即下架 |
| 安全 | QUIC 互认；伪造设备和越界目标被发布端拒绝；撤权中断已有流；控制面失联后授权按时过期；切换物理网络暂停 |
| 原应用 | 两个网络间用普通 TCP 客户访问原地址；同 IP 不同端口命中正确设备；有重叠时原地址仍走本地，虚拟地址与 `.fesen` 别名访问远端 |
| 失败 | 区分设备离线、无法直连、发布/本地地址冲突、未授权和目标超时 |
| 连通测试 | 点状态或主机卡片检测按钮，经直连和发布端 ACL 检测目标 `IP:端口` 并返回端到端耗时。普通 TCP/SMB 仅验证建连；SSH 仅被动读 Banner；RDP 仅发 X.224 协商包；HTTPS 验证 TLS ServerHello（兼容内网自签名）；HTTP 实际请求 `GET /` 且仅有效 2xx 可用，不跟随重定向；本地重叠不误报原地址可用 |
| 单机识别与聚合 | 发布端「按主机添加」拒绝保留地址与超量端口，在 1–1.5 秒内识别单机开放服务与系统标识（SMB 默认不强勾），无需目标机密码；同 IP 多端口在发布端与访问端均自动聚合为主机卡片并支持整机开关与按协议复制连接命令 |
| 网页验收 | 点 HTTP 服务行的「网页测试」弹出应用内网页视图，可重试、关闭回原列表；显示网页或失败原因，不以弹窗已打开当作网站可用。发布端本机预览单独标注，重叠时用虚拟地址 |
| 生命周期 | Windows/macOS 关窗后 GUI 进程消失，已有流不中断；托盘或菜单栏不加载 WebView；无任务时核心退出并释放路由、监听端口。Android 13+ 接入即建立系统 VPN，打开界面不自动接入，空目录不加默认路由，不申请通知权限；停止后释放 TUN 与前台服务 |
| 界面 | 遵循 [视觉与交互规范](design.md)：全端共用 `packages/ui` 与八卦状态组件（死门 ☷ → 单爻演卦 → 生门 ☶）；跟随系统深浅色，支持简体中文和英文；桌面默认 `430×740` 移动端比例、客户端与 Web 管理台统一单行顶栏与卡片列表；Android 避开系统栏及键盘并支持快捷磁贴；macOS 显式申请扩展并区分签名和批准问题 |
| 日志 | 本机保留，累计不超过 10 MiB、日志在线时最长 7 天；检查不写入密码、令牌或数据内容 |

共有逻辑通过单元与黑盒测试。虚拟网卡、系统 DNS、签名授权、关窗/通知停止、真实 NAT 直连分别在对应平台验收；交叉编译不计作实机通过。
